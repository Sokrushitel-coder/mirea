# MIREA — учебные проекты

Репозиторий с учебными проектами, лабораторными и практическими работами за время обучения в РТУ МИРЭА (Институт информационных технологий).

## Структура репозитория

| Папка | Описание |
|-------|----------|
| `java` | Практические работы по дисциплине «Программирование на языке Java»: основы, ООП, интерфейсы, коллекции, GUI (Swing), регулярные выражения, паттерны проектирования |
| `питон` | Проекты на Python |
| `информатика` | Лабораторные работы по информатике |
| `сиаод код` | Код по дисциплине «Структуры и алгоритмы обработки данных» (СИАОД) |
| `симулятор качалки` | Симулятор качалки |
| `конфу` | Работы по конфу |
| `тфя` | Теория формальных языков |
| `РБД СКРИПТЫ.sql` | SQL-скрипты для работы с реляционными базами данных |

## Используемые технологии

- **Java** — Java SE, Swing/AWT, коллекции, generics, regex, паттерны (MVC, Abstract Factory)
- **Python** — Tkinter, requests, matplotlib, работа с XML API
- **SQL** — реляционные базы данных
- **Git** — система контроля версий

## Быстрый старт

Каждая папка содержит независимый проект. Для запуска:

### Java

```bash
cd java
# Откройте проект в IntelliJ IDEA или скомпилируйте через javac
javac Main.java
java Main
```

### Python

```bash
cd питон
pip install -r requirements.txt
python main.py
```
